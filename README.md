# EVE Profit Analyzer AI

This project is a cloud-native web application that automatically identifies and ranks the top 100 most profitable trading items in EVE Online, using EVE ESI API + Everef data and Google Vertex AI for machine-learning-based price and profit prediction.

## Project Structure

- `backend/`: FastAPI backend application.
- `frontend/`: Next.js frontend application.
- `docker-compose.yml`: For local development.
- `README.md`: This file.
